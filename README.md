# JavaProjects

Spare-time Java learning artifacts.

## Trust warning

This repository currently publishes **compiled `.jar` binaries without accompanying source**.

- Do **not** run these jars on production systems or untrusted hosts.
- Treat them as unauditable binaries from a supply-chain perspective.
- Prefer rebuilding from source once source is published, or delete jars you do not need.

If you clone this for portfolio browsing, inspect artifacts offline only.
